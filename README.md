# Do A Barrel Roll for Horizon

Do A Barrel Roll is a native mod for Horizon, written in Rust. It lets you fly the elytra like a plane. It is not a port of the Java mod. It's a new mod written from scratch, and it borrows only the basic idea. It contains none of the Java mod's code, and it isn't affiliated with the Java mod's authors.

## What it does while you glide

- Moving the mouse left or right rolls the camera, and moving it up or down pitches.
- Banking the wing turns you, the way a plane does.
- A and D steer left and right without rolling.
- The roll levels out when you land.
- A settings page lets you change the roll speed and turn banked turns, A/D steering, auto-level and camera roll on or off.
